# V5 云端浏览器阻断原始记录

> 本文记录的是上传云端成品包时的浏览器环境限制，不是当前集成分支的最新结论。本地 Chrome 的后续交互和截图见 [V5 集成与本机 Chrome 验收](集成与实机验收.md)。

结论：**受环境策略阻断，未完成。**

尝试方式：云端 Python Playwright 启动现有 Chromium，访问已成功启动的本地游戏服务 `http://127.0.0.1:4188/`。

返回错误：

```text
Page.goto: net::ERR_BLOCKED_BY_ADMINISTRATOR at http://127.0.0.1:4188/
```

环境的 Chromium 托管策略包含 `URLBlocklist: ["*"]`。没有修改、绕过该策略，没有将其他工具生成的画面当作浏览器截图。

以下项目均未获得本次实机通过结论：1080p、1440p、模拟 4K 的文字遮挡与整体滚动；首屏、八品质奖励演出、Boss 换相与全部页面的实际视觉；1 / 3 / 6 骰的鼠标或键盘交互；购买、融合二次确认、刷新去重和三遗物操作在 DOM 中的完整链路；声音听感、WebGL 实际表现、长帧及硬件帧率；Windows 原生 `.cmd` 启动。

包内完成的是：实际 Node 游戏规则转换、存档编码/解码、HTML 生成函数测试、静态模块语法检查，以及 HTTP 服务与资源路径测试。这些证据支持功能和状态一致性，不能替代上述浏览器操作。

保留的 `docs/screenshots/gameplay-desktop.webp` 来自原始 V4 输入，不是 V5 截图。没有生成假 UI 概念图来替代缺失的实玩证据。

> 历史图像归档说明（2026-10-17）：此图现为 1600×900 的 WebP 压缩浏览副本，原图为 1920×1080；它不是本轮迭代的新截图。原测试结论不变，来源与压缩说明见 [V4 截图说明](../screenshots/README.md)。

## 后续独立浏览器验收的范围（上传包时尚未执行）

优先验证 Windows 桌面上：标题页 → 新开局 → 手动命运骰 → 第一场战斗 → 开箱 → 刷新不重复领取 → 换装 → 商店成交 → 锻造与受保护融合 → 三遗物 → 图鉴与五路深层天赋。随后用明确标记为调试起点的深层存档覆盖八品质揭晓、所有新房间、新 Boss 和低血/满包/金币封顶状态。

检查 1920×1080、2560×1440、3840×2160 的全页与内部滚动、长名称、概率标签、卡片、对比文案以及系统字体回退；用同一设备、同一浏览器、同一渲染后端比较 V4/V5，不把软件渲染结果说成独显性能。

其中第一层主要流程、30/50/80/140 层奖励、深层天赋门槛、锻造、三遗物融合、十种新增深层事件、隔离 V4 合成档导入、满背包写入/失败重试、V4 字体对照与三种模拟视口已在本地 Chrome 执行。真实私人旧档、自然长线真人推进、原生 `.cmd` 双击、听感和物理 4K 性能仍然待验收；详见当前验收报告。
