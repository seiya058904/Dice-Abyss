# Round26 · 性能实测与代价

## 结论与环境

本轮确认两处局部 CPU 收益：万件标准背包的三种排序都在 12/12 对样本中更快；固定骰子轨迹的边界计算也在 12/12 对中更快。原生筛选在本批样本中改善，原生首次打开极值、翻页中位数及部分动画帧尾部仍有退步。**不宣称整体 FPS、全部交互或性能不劣已获证明。**

输入是实际上传 v5.25.0，当前 v5.26.0。Node v24.19.0、Linux x64；浏览器 Chromium 155.0.8059.84，ANGLE Vulkan SwiftShader 软件后端，DPR 1。页面只访问隔离本地服务，使用可验证的合成存档；没有读取私有用户存档。所有正式计时在完整测试和模拟结束后串行运行；一次预声明批次，没有为获得有利结果追加替换样本。

[预声明协议](https://github.com/seiya058904/Dice-Abyss/blob/8f7d5d0fcade3e8467e52f27e0303e4137ab748a/docs/iteration/evidence/round26/PERFORMANCE_PROTOCOL.md) 与完整报告位于 `evidence/round26/performance/`。以下每张表都为输入 → 当前；统计口径不能交叉代用。源码 HTTP/本地身份、前后不变、完整 DOM 和主/镜像存档均通过各自驱动检查。

## 2. 骰子边界：CPU 函数批处理

先用旋转不变的包围球和保守透视区间，证明当前所有骰子完全落在旧包络内。无法证明、首帧、静止、尺寸重置、无效数值、近裁面或包络扩大时，执行原始八角点投影。四像素外扩与六字段返回结构保持一致。

144 条轨迹、22,320 个供给帧中，18,534 帧进入快路径（83.04%）。全部六个边界字段逐帧严格相同；角点 **624,960 → 168,480**，三角函数 **468,720 → 126,360**，两者均减少 **73.04%**。这里 83.04% 的帧比例与按骰子数加权的 73.04% 工作量比例不同。

每个正式样本重放完整 144 轨迹 / 22,320 次函数调用，1 次预热/版、12 对交替 A/B。计数和计时分开，计时没有计数器或像素读回。分位数为 floor((n−1)×p)，n=12 的 p95/p99 是次大值。

| CPU 批次 | 输入 ms | 当前 ms | 降幅 |
| --- | ---: | ---: | ---: |
| p50 | 63.076190 | 19.518078 | 69.06% |
| p95 / p99 | 69.902029 | 22.106796 | 68.37% |
| max | 70.501014 | 24.275935 | 65.57% |

**12 快 / 0 慢 / 0 同**。这是包围盒函数成本，不是 22,320 个真实浏览器呈现帧，不可将 69% 写成 FPS 提升。原始证据 `dice-bounds-formal.json.gz` 与独立摘要完整保留。

## 3. 原生万件背包：完整点击到第二 RAF

1920×1080、DPR 1、low effects、reduced motion，固定 10,000 件合法构造背包。每次新上下文依次执行打开、武器筛选、下一页；每动作每版 12 正式样本，另 6 预热动作，总 78 行。使用可信原生 click，不以 evaluate 直接调用动作。floor-rank 分位数，p95/p99 在本样本数下为次大值，max 独列。

筛选 p50/p95 分别下降 **12.5% / 12.6%**，9/12 对更快。翻页 p50 升高 **6.2%**，7/12 对更慢；翻页已有的跨页复用属于输入功能，不能重复计功。打开 p50/p95 较低，但最大样本 **162.4 → 361.3 ms**，不能称所有打开更流畅。

当前打开 pair6 的 361.3 ms = 首次 RAF 等待 110.1 ms + 两次 RAF 间隔 251.2 ms；记录的 LongTask 为 110 ms。只能确认本次极值主要多在第二 RAF 等待段，不能据此归因 GPU、调度、GC 或本轮某一行代码。保留原样本，下一轮应按阶段做因果诊断。

完整 DOM 和两份保存原字节均通过。额外独立检查了旧驱动历史排除的回收提示区域：两版 `reclaimReferences`、全部 78 行 `reclaimHtml` 逐字相同；每动作 26 行完整 `actualDomSha256` 相同，60 卡 ID 与顺序相同，本轮没有依赖排除区放过变化。

LongTask 数量：打开 **12 → 12**、筛选 **12 → 11**、翻页 **0 → 0**；最大任务分别 **157 → 110**、**85 → 76**、**0 → 0 ms**。LongTask 数少不能替代完整输入延迟。

## 5. 图像、功能与未测边界

严格 RGBA、离屏/返回、真实上下文恢复、滚动、焦点与缩放使用独立功能驱动，不进入任何正式计时。当前结果及微小像素差异详见 [VERIFY](VERIFY.md)。几何字段相同不自动证明原生全部 RGBA 相同；历史 Canvas 1/18、GL 2/7 严格失败仍保留。

物理 GPU/显示器 4K60、Windows 真机、实体手机、音效听感、外部读屏、实际断电及 JS heap 峰值没有在本环境认证。当前短模拟不替代历史 4×400 层自然队列缺口。存档、安全、滚动和画质要求继续保留，相关长尾没有在这轮全部解决。
