# Round 04 evidence

This directory contains current-round evidence, not runtime assets. Exact output ZIP identity is external; FILE_MANIFEST hashes these files.

- `baseline-*`: freshly executed on the read-only uploaded 5.4.0, not inherited PASS reports. Functional gate durations ran alongside other regressions and are not performance measurements.
- `gameplay-*`: eight natural-engine automated journeys (2,000 floors), exact forge/spring differentials, and their limitations. The 200-floor report's four log-only ability counters are missing coverage, not zero real activations; see gameplay-notes.
- `storage-performance-round04-formal.json`: 20 counterbalanced pairs per size/operation in a reserved team window, Node plus in-memory Storage. `...-development.json` retains excluded concurrent-load exploration. No sample is removed from either raw report.
- `renderer-rejected-all-gap-*`: the abandoned candidate that clamped every scheduling gap. Its 62-window matrix and six independent-process diagnostic windows are NOT the final renderer's performance. Their negative findings caused scope reduction to first-sample-only correction.
- Renderer final evidence, actual browser regression reports and package candidate gates are added under clearly distinct names. An earlier or synthetic success never stands in for physical GPU, Windows, phone, screen-reader, audio or power-loss validation.
- Absolute paths and loopback URLs inside raw reports identify the run environment only. Reproduction scripts accept the tester's own source/output/browser paths; the game has no dependency on this session's temporary directories.
- Current-source tests, scripts, fonts and licenses remain in the complete project. Large temporary videos, unselected concepts, browser profiles and raw PNG sets are excluded. Selected true screenshots are compressed with provenance in `visual/manifest.json`.

- `current-fusion-browser-summary.json` combines the 11 initially successful groups with the one separately verified page/target group after native visible-tooltip dismissal (125 distinct checks). It does not claim a second full-suite run. Both initial timeout reports and the independent two-version obstruction/recovery remain.
- `qa-driver-corrections.json` includes exact patches and frozen hashes for only two QA drivers; all original assertions remain. `final-source-identity.json` binds the actual shipped source/tests/scripts set to the full-gate and post-correction evidence.

- `fresh-code-verification.json` and its logs are actual acceptance of the named code-identical candidate ZIP (120 core cases, 38 HTTP resources). Its bytes/SHA identify that candidate only. The final ZIP is built after these small records are included, then re-extracted and rechecked; final self-identity is external.
- `packaging-development-failure.json` records the first temporary wrapper using the wrong extraction cwd before any core tests; the unchanged verifier had already passed CRC/manifest/extracted bytes. The corrected run uses the preserved Dice-Abyss subdirectory in another empty destination.
