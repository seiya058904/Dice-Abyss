# Round 14 证据入口

本目录属于 V5.14.0，唯一实际输入是 V5.13.0 / Round13 完整 ZIP。本轮使用的只读基线、候选、最后冻结源码和最终实体 ZIP 是不同验证阶段；不把早期候选的结果改写成最终通过，也不把历史报告算作本轮运行。

## 文件分工

| 目录 | 内容与阅读顺序 |
| --- | --- |
| `validation/` | 输入身份与预算、完整基线和当前单测／模拟／HTTP轻量结果、完整 TAP、独立源码／字体／旧文件保留、原有浏览器报告与最后生命周期。`current/independent-review-postfreeze.json` 记录最后局部补丁后的闭环。 |
| `gameplay/` | 自然四种子的原失败与完整报告、215 条同终态分支的可读摘要／详细小样本／无损共同原件、完整 A/B 比较、两轮死亡页面浏览器报告、真实手动救援后的完整状态、六张真实截图及原 PNG 身份。 |
| `performance/` | 普通正式矩阵、预先固定的 A/A／反序控制、单独侵入式诊断、Canvas 命令对照、严格像素差异及必要原 RGBA。完整数据恢复与路径见 PERFORMANCE。 |

所有基线与当前模拟原始 `simulate1000.stdout` 各 9,409 字节相同。当前首完整候选细项 587，之后一个描述类型测试使最终预期为 588；冻结后四新增模块独立 17 项通过。最终实体 ZIP 的实际细项、CRC、完整 manifest、解压字节和 HTTP 门禁回执在包外交付记录中产生，避免 ZIP 自身哈希及测试自引用。

## 不能混淆的统计

- 四自然种子各目标 400 层，两版都是 3/4 完成，23757 的失败原样保留，exit 2。
- 215 条单件／槽位分支共享一个事后终态，3 胜／212 死不是新的自然通关率。
- 第一次新 UI 6/11 组通过、5 个桌面焦点失败；修正后的 11/11 与 443 检查才是最终 UI 结果。
- 52 场完整 Canvas 命令相同，不等于所有原生像素都相同。18 场像素中有 1 严格差异，同源码 A/A 也可复现。
- 普通性能第一轮大背包 p50 125.0→244.8 ms，反序仍 107.3→124.7 ms；同源码 A/A 的上下文差异也很大。保留不利观测并标未稳定归因，不称作稳定提速或无回退。
- 8 窗 trace 是侵入式诊断，可能与审阅者一次意外 CPU 负载重叠；不与普通矩阵混算。模拟可见性、合成调试存档、软件 GPU 和物理设备分别标注。

## 体积与复现

不随包积累巨型 trace、所有 PNG、浏览器 profile、输入副本、空日志或重复的全项目文件列表。`archives/round13-manifest.json` 保留输入完整清单；最终完整清单为上一级 FILE_MANIFEST。轻量选择不会删除失败样本或更改原始数值。

`node scripts/restore-round14-evidence.mjs --output /tmp/round14-full-branches` 只用 Node 内置模块恢复两份完整原分支 JSON，并验证每份原长度／SHA。原始临时绝对路径是出处记录，项目运行与当前源码测试不依赖这些目录。QA 新输出请放项目外；运行与复验命令见 VERIFY。
