# Round24 UI 独立审阅

结论：发布回收报价按点击计算；不发布 CSS 离屏卡片候选。不提供最终 FPS 或整体性能无回退保证。

## 运行代码范围

`src/views.js` 浏览背包时不再执行全包报价，改为“检查可回收旧装”。`src/app.js` 点击后调用原报价、确认及交易路径。空报价同时提供 toast 和可访问公告，覆盖无候选与合法大数累计金额超出安全范围两种情况。

引擎、保护规则、完整 expected、Web Locks、主镜像、结算及 RNG 未因这项优化改变。`responsive.css` 与输入逐字相同；未固定卡片高度、裁字或删除内容。

## 回收语义验证

新增 `inventory-on-demand-reclaim.test.mjs` 的 8 个原生案例全部通过，覆盖浏览、完整预览、取消、交易、空反馈、大数拒绝、保护变化和金币上限。旧测试未削减或放宽。

`audit-inventory-on-demand-round24.mjs` 的非 timing 执行通过 36 组 HTML 比较及 3 个应用处理器场景。仅规范按钮和版本，其余 HTML 字节相同；报价、确认及完整最终存档一致。资格读取探针在浏览时从 1 次降为 0 次，点击报价仍为 1 次。结果：`reclaim-semantics/report.json`。

## CSS 候选拒绝证据

隔离原生 Chromium 在同一运行源码上比较无 CV 与注入 `content-visibility:auto; contain-intrinsic-block-size:auto 22rem`。控组原库存导航 QA 通过 176/176 检查，另一个万件原生输入控组通过 232/232 检查；均无浏览器异常或控制台错误。

1366×768 下，列表滚到 900px 后打开设置、切换特效，候选可见卡上移 25px；控组不动。1920×1080 万件深处，候选设置重绘使锚点偏移 21px，关闭后仍保留；控组偏移 0px。两次均保留原 1 CSS px 门槛。

万件候选为 230/232，失败仅为上述两个锚点检查。32 次滚轮、48 次 Tab、翻页键及首尾键、深处三项锁定和存档核验通过。原导航驱动另覆盖四桌面尺寸和 390px 重排。

首次探索只等四个 rAF，控组与候选均对未结束的 PageUp/Home 滚动过早判错。原始失败保留；驱动等待实际滚动稳定后重跑，未替换 API。随包 `qa-content-visibility-rejected-round24.mjs` 仅 QA 注入 CSS；exit 0 表示控组通过且已知候选缺陷复现，不表示候选通过。

原始 audit 证据名称：`css-nav-none/report.json`、`css-nav-22rem/report.json`、`css-native-input/report.json`、`css-native-input-confirmed/report.json`。未推测最终归档链接。

## 离屏渲染审阅边界

只读审查 effects、dice-renderer、visual-timeline，未见 P0/P1 或游戏 RNG 改动。观察器防护、清理、最新姿态恢复和 GPU/DOM 切换合理；闪电随机消耗先于可见性判断，保留序列。

“滚出视野→动画结束→滚回静态终态”的原生组合验收交 root，代码审查不能代替。隔离 Chromium 已全部关闭，未新增正式性能采样。

## 正式筛选负结果与固定 2×2 诊断

最终建议仍为保留按需回收。该判断限于保留已经验证的无用计算削减，不代表背包整体加速或筛选无回退。

原完整 5.23→5.24 原生 A/B 必须保留：`inventory-formal/report.json` 的万件筛选 p50 为 57.1→65.5ms（+14.7%），p95 为 63.9→73.2ms；12 对中 8 对更慢，逐对平均 +5.05ms，样式重算耗时 12/12 对更高。这是未解释的真实负结果，不能归为“噪声”，不能用 Node CPU 改善或后续消融覆盖。Node `reclaim-cpu/report.json` 万件 HTML p50 8.167→7.354ms、11/12 对更快，夹具和计时范围不同，不能换算成浏览器收益。

root 随后运行固定诊断，本审阅仅分析既有数据，未重新采样。`reclaim-factorial-formal/report.json` 保留 4 个单列预热、32 个正式样本，无错误、无弃样，源码身份、完整 DOM、60 卡及主镜像字节均通过。A/B/C/D 分别为“计算＋旧控件”“计算＋新控件”“不计算＋旧控件”“不计算＋新控件”；除 views 外均为 current 5.24，且旧报价在固定 seed27017 万件夹具上已断言为 null。控件因素同时改变文案、disabled、aria/title；这是消融诊断，不能替代完整版本 A/B。
