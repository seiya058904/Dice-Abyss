# Round24 证据导航

本目录对应上传 v5.23.0 → v5.24.0。`archive-index.json` 将原始执行文件映射到随包路径，记录原字节数、SHA-256、压缩字节数和存储 SHA。`.json.gz`、`.mjs.gz`、`.log.gz` 都是无损原件，Python 标准库 `gzip.decompress` 即可读取；归档时逐份实际恢复核对。原报告中的绝对路径是执行记录，不是游戏或复测的运行依赖。

## 权威层次

- `../../STATE.json`、`../../LATEST_REPORT.md`：当前交付身份与结论。
- `../../PERFORMANCE.md`、`../../VERIFY.md`：按测试口径分列的收益、负结果、通过项和未验收边界。
- 本目录原始报告：样本、预热、分位、最大值、完整断言、HTTP/源码身份。
- `baseline/provided-reports/`：输入包的上一轮顶层报告，仅供历史对照，不能算本轮执行。

| 路径 | 内容与边界 |

| `baseline/` | 输入实体审计、原始清单、早期运行差异快照、上轮报告，以及可精确恢复输入运行字节的 gzip 原件与 manifest。 |
| `verification/baseline/` | 本轮重新执行的输入版 check、npm test、逐模块原生 TAP、1000+50 模拟及 HTTP 尝试；失败的首次沙箱 socket 记录一并保留。 |

| `browser/` | 原脚本的核心流程、背包与交易、服务/锻造/融合/天赋及动画生命周期实际报告。合成存档和受控 visibilitychange 按原报告标注。 |

| `exploration/` | content-visibility 初测、布局/原生输入拒绝证据和当时驱动。候选已撤回；更快的初测不是发布版指标。首次过早读取平滑滚动造成的误报也保留。 |

## 复测与证据解释

运行游戏只需 Node 20+ 和浏览器，无需安装 Playwright 或 Python。QA 驱动使用测试者自己的浏览器依赖，路径通过参数/环境变量给出；未将本机 Chromium、下载缓存、依赖目录或私人存档收入包内。先使用 `scripts/restore-runtime-baseline-round24.py --output <全新外部目录>` 恢复输入运行代码，再分别启动输入/当前服务器。恢复器不伪造历史测试或文档。

性能驱动要求全新输出目录，避免覆盖失败或慢样本。正式计时串行执行，不与本任务全套测试、模拟或第二个浏览器争用本机。共享主机上的其它负载无法控制，所以原始长尾必须保留。`MEASURED` 表示测量完成，不表示性能门槛通过；Canvas 命令相同、DOM 相同、严格 RGBA 相同是不同判据。

高频采样里的 160/240 是驱动提供的回调时间序列，不是硬件刷新率或 FPS。离屏优化仅在观察器已经报告整个画布不可见后阻止绘制；初始化、保守飞行包络、时钟和少量视觉随机序列仍运行。交叉版本 2 个严格像素失败及同版本重复性失败均保留，零容差不变。

本轮新增代表截图只保留少量可检查画面；其他场景由原始断言、尺寸、完整脚本与固定夹具复现。严格比较的全部原始 RGBA 无损压缩字节保留，不能拿视觉截图替代它们。
