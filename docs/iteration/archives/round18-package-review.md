`FILE_MANIFEST.json`按相对项目根路径稳定排序，列出每文件实际bytes和SHA-256；只排除清单自身。`fileCountIncludingManifest`是当前文件集合真实数。ZIP内统一 `Dice-Abyss/` 根目录，普通ZIP DEFLATE压缩，不拆包、不以外链替代运行文件。
