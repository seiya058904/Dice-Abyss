## 玩家实际得到的改变

1. **黄金房先显示可收，结算后写实收。** 相同958奖励在仅剩10容量时明确“可收10 / 将超出948”，满额时说明0与继续前进。命运双同、开箱和日志也按真实差额表达；不更改原奖励、掉率或RNG。
2. **待开箱和已开箱各有准确含义。** 未开箱只展示金币预测，不泄露物品；开箱后保存当次实收，之后花钱、换装、回收、刷新仍显示这次收入。旧历史没有回执时标注“未记实收”，不从当前余额猜测。
3. **交换前看清装备代价、金币与经验。** 金币满额仍可按原规则取得XP；若经验容量也满，确认和结果明确金币/经验均0且物品永久消耗。经验计入量按升级前容量计算，不把升级消耗后的余额差误当收入。
4. **融合区分“钱暂时不足”和“超过可持有上限”。** 普通不足仍可按预算调整；超限真正禁用并提示换目标或减少材料，保留已选材料；恰好100亿仍可真实支付。内部哨兵不再作为真实价格，也不出现−1余款。
5. **关键金额看得清且不挡按钮。** 收益、损失、余款与回收确认使用完整分组整数，容量状态附明文；新增账目沿用原字体/图标/配色，无额外动画。四桌面视口的16个金币布局状态首屏可读，房间面板与操作区无重叠。

相应证据为新增6模块40用例、金币原生7组316检查、融合容量8场218检查、独立事务与页面复审。普通非溢出结算字符串保留；回收原有保护/allowOverflow与满背包管理优先级保留。没有新增货币、物品品质、敌人或支付机制。
