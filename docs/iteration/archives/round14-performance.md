# 性能与特效审计 — Round 14 / V5.14.0

## 1. 当前结论与未关闭问题

本轮正式性能状态为 **MEASURED_WITH_LIMITATIONS**。万件背包状态为 **OBSERVED_SLOWER_UNATTRIBUTED / OPEN_RISK**：首次版本 A/B 的 p50 从 **125.0 ms 增至 244.8 ms（+95.84%）**，p95 从 **343.4 ms 增至 512.1 ms**，max 从 **427.7 ms 增至 651.8 ms**。反序版本 A/B 的当前 p50 仍慢 **17.4 ms（+16.22%）**。这些不利结果完整保留，不能宣称已证明无回退、背包提速或性能验收全绿。

本轮可证实的生产改进仅为 [effects.js](../../src/effects.js) 中减少重复几何读取和无意义的 DOM 移动。真正输入模块与当前模块的 **52/52 场景 Canvas 命令完全一致**，累计少 **49 次 getBoundingClientRect、29 次 prepend**；材质、像素预算、视觉时长与 RNG 没有改变。这是操作次数的减少，不是 FPS 或布局耗时改善的测量结论。

正式矩阵中的软件 4K 秒级长帧仍存在。当前 4K 永恒 full 两窗的 max 为 **9,273.6 / 4,776.1 ms**，两窗均没有观察到 `loot-7`；主矩阵共 **7 个 full 目标阶段未观察窗口**。所有 16 个永恒窗口的骰子像素峰值均为 **0**，不能继续归因到骰子几何。后续 8 个侵入式归因窗口没有复现这些秒级尾部，且无法排除一次意外 CPU 竞争，因此没有关闭其根因。

原生 Canvas 严格像素对照完整跑完 18 场景，**17 通过、1 保留严格差异**。同一输入源码的独立上下文 A/A 三次都出现相同的两个差异字节，说明该差异不要求存在本轮源码修改；这仍不能写成所有原生像素普遍相同。没有放宽阈值或把失败改记为 PASS。

本轮性能入口为 [证据导航](evidence/round14/performance/README.md)、[派生汇总](evidence/round14/performance/SUMMARY.json) 和 [无损归档清单](evidence/round14/performance/MANIFEST.json)。下文的原始路径均指按第 10 节解包后的目录；报告与完整 DOM 使用 gzip 无损保存，没有裁剪字段或丢弃慢样本。

## 2. 生产改动的准确范围

`prepareCanvas` 以前无条件读取中心 panel 两次，即使战斗路径稍后会用 combat stage 的宽高覆盖这两个结果；奖励路径则再次把原本已在第一位置的 Canvas `prepend` 一遍。当前战斗只测真正拥有画面的 stage，奖励只读取一次 panel，并在 Canvas 已是第一子节点时跳过移动。Canvas 自身的实际边界读取、ROI 计算、裁切变换和像素分配顺序保留。

| 路径 | 直接可证实的调用变化 | 保留的行为 |
| --- | --- | --- |
| 战斗 Canvas 准备 | 少 2 次无用 panel 边界读取 | stage、dice、damage 的原坐标与裁切算法 |
| 奖励 Canvas 准备 | panel 两次读取合并为一次 | 原逻辑尺寸、Canvas 自身边界读取与材质尺寸 |
| Canvas 已在 panel 第一位 | 跳过一次 `prepend` | 原生产 DOM 顺序 |
| Canvas 不在第一位 | 仍执行 `prepend` | 异常/复用 DOM 下的归位行为 |
| 空闲、low、reduced、rolling | 没有进入新增优化的准备路径 | 原返回、骰子、时间线与清理行为 |

默认预算仍按 viewport 分为 **840,000 / 760,000 / 660,000 像素**，DPR 上限仍为 1.5；ROI 裁切后实际 buffer 可以更小。这些来自输入的既有预算没有再降低。八品质粒子、列光、环数、材质 cache 与生命周期、骰子着色器/索引网格/图集/运动预算均沿用输入。旧的 Round 13 索引网格改进仍在，但它不是本轮新增收益，也不能解释没有骰子的开箱长帧。

[audit-effects-layout-round14.mjs](../../scripts/audit-effects-layout-round14.mjs)直接读取只读 V5.13 模块，与当前模块在确定性 DOM/Canvas/clock 中逐条比较完整命令参数、属性赋值、path、gradient、材质创建、几何、保存状态和取消清理。52 个案例包含 390/1920/3840、八品质、战斗/首领/充能、low/reduced/rolling/idle，以及非第一子节点和中断。独立复跑得到同样的 52/52、49/29 差额。新增 [effects-layout.test.mjs](../../tests/effects-layout.test.mjs)保留这几个行为门禁，原 [effects.test.mjs](../../tests/effects.test.mjs)没有删改。
