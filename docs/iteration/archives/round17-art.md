# Round 17 · 视觉方案与资源预算

本轮原创视觉是与现有黑金属界面一致的 CSS 信息层级：金色本层状态、紫色未用储备、青色首掷临近提示，均同时有名称、数值与生效时机。新效果没有持续动画，也没有给骰体增加材质、纹理或像素预算。

确实考虑过原创位图、角色插画/纹章与较大的装饰卡面；它们无法说明本轮核心的“什么时候生效、支付后剩多少”，而且会占用密集桌面。实际落地并在浏览器比较的是自绘 CSS 色带、细分隔线、语义分组和卡片数值层级，复用项目已有 SVG 图形。**本轮 imagegen 调用0、新运行位图0、新字体0、新音频0、新依赖0**；不把浏览器截图称为AI生成美术。

## 已验证的视觉结果

- 保留手掷骰子的中央焦点与固定主要操作区；首掷读数放在骰子上方，完成冲击演出时不闪现错误待用信息。
- 确定事件卡片中，原价格/奖励之后显示“选择后的即时状态”；金币、HP、等级、强化均写 before→after，目标名称作为文字安全转义。
- 新说明正文最低12 CSS px，文本可换行。窄屏为可滚动桌面游戏兼容布局，未宣称物理移动设备完成适配。
- 侧栏增益项多时可滚动，同局重绘、设置切换及天赋往返保留位置；新局清除本地展开/滚动。
