### 兼容边界

null、已发行后被回收的 ID、换下或锁定的原武器，以及 resolved 历史引用保持既有语义。材料的锁定/装备/高品质保护阻止消费；目标锁定不阻止升级和保留。只检查待处理事件真正使用的引用，无关 metadata 不当作交易对象。重复或未发行 ID 明确拒绝，不自动重排和修复。

正常入口从安全旧物和入场武器分别登记，因此 S01/S02 是构造导入边界，未证明自然流程经常吞装。已经损失的历史装备无法可靠重建，本轮不会臆造赔偿。
