# Round 18 · 长期玩法、策略与内容复审

本轮不改战斗数值、概率/RNG、房间分布、装备/敌人/Boss/天赋表；用真实旧失败重新判断现有装备是否已经提供不同选择。实验是从新开局经合法引擎动作推进的离线脚本旅程，不是人工连续400层实玩。所有种子与停止条件预先固定，错误与未完成都保留。

## 规则先于战果

正式v2声明SHA-256：`1adea070563a8bf6826a171c47e32615c34bbbaa908edc948ba1e9acb625cfff`。

规则只用当时已显示的结算反击、同掷防御及按UI精度的百分比属性，在固定12次压力启发式中比较防具；策略函数没有种子、RNG或未来结果输入，没有把每件装备试战后挑胜者。首次干预前完整状态与独立原协议首败前缀一致。模型不是生存保证，也不宣称取得全局最优构筑。

开发v1误把enemyIntent.attack当作可见字段。源码核对发现实际UI只给伤害区间后，在任何候选换装战果被查看前主动停止，exit130；原声明、代码、日志保留在strategy/development。正式v2重新声明后才执行，上述结果不混入v1数据。

## 30层的实际选择

首次失败在30层、累计471掷。规则选中已有传说防具i123“永恒·破晓灵衣”，替换i127“永恒·霜痕壁垒”。两者实际rarity均按档案字段判断；名称中的“永恒”是历史装备名称组成，不是第8档品质提前掉落。

| 当时属性 | 原防具 | 选择的防具 |
| --- | --- | --- |
| 最大生命 | 3,067 | 2,616 |
| 防御 | 151 | 159 |
| 减伤 | 6% | 0% |
| 存活恢复 | 0 | 5%，当时每次存活掷骰恢复130HP |
| 基础暴击 | 34% | 36.5% |
| 基础生存估值 | 基准 | −9% |

换装时HP仍0，RNG、敌人、背包和金币不变，之后由原规则重燃，按新构筑恢复生命。首领再经26次真实引擎掷骰被击败，累计497掷完成30层。33层原离线日常选装策略选回旧防具后再次战败，固定规则再次选择i123，此后到400层没有新死亡。日常自动选装是模拟器策略，产品并没有替玩家自动换装。

新装降低生命和减伤、增加恢复及暴击，击杀时点和后续随机轨迹也可能自然分岔。因此不能把400层结果只归因于恢复，更不能据此直接改平衡、宣称普遍胜率提升或削弱Boss。

## 下一项可操作体验

首败真实背包139件物品、48件防具，其中14件含持续恢复。原按名称搜索“恢复”“防御”“护盾”均0。搜索遵守名称契约，发现机会是让玩家主动按防御词条筛选、保留原装备比较，让已有构筑更容易找到。本轮没有继续增加UI、内容表或自动推荐；已把证据样本和预声明规则留给下一轮。
