## 回流、键盘与布局

3个新增信息密集场景 × 1366×768、1920×1080、2560×1440、3840×2160、390×844、320×812，共18个组合。每个记录页面横向宽度、新节点裁切、字体加载/最小字号、主操作可达，共90检查。通过不等于所有既有控件都满足整站无障碍规范。

主整合者实际看过1366的祈愿/索光/归潮，以及320全文页面图；新增文字没有横向裁切。桌面侧栏需要滚动时能到达所有规则。窄屏固定操作条会占据视口底部，内容靠正常滚动到达，仍是桌面优先产品；没有以320 CSS px自动宣称真手机可用性和性能已验收。

Space在native summary只展开详情，不投骰或改档。设置重绘/天赋往返保持当前同局详情与953px滚动的实际测试通过；VM模型另测180px只代表逻辑，不拿它替代浏览器像素。新局重置为折叠/滚动0，浏览器整页reload的UI偏好不作保留承诺。

## 测试驱动失败的处置

主批首次误把已关闭确认框内残留预览计作仍有效选项；修正为事件屏幕内的选择卡片，并明确检查确认框已关闭。另两次详情流程命中隐藏设置中的home/new同名控件；最终驱动限定实际标题按钮，定向11项通过。它们是驱动选择范围错误，原报告保留。

原通用融合驱动使用旧 `fusion-target` 标记，当前版本已使用工位。未为过时测试改产品或删除原驱动；另用已有当前专用驱动完成真实融合验证。证据计数由 [browser-accounting.json](evidence/round17/browser-accounting.json)逐组记录，不把失败前的9项、重复阶段结果或不同口径加成虚高总数。
