# Round15 · 搜索、背包整理与页面复核

日期：2026-10-19 UTC。当前 V5.15.0；只读基线 V5.14.0。最终搜索验收 **10/10 组、171 检查、0 失败**；死亡备战验收 **11/11 组、629 检查、56 次完整状态比较、0 errors**。检查数、状态比较与场景组不相加为独立样本。

## 搜索的实际行为与范围

在 Chromium 155.0.8059.84 的隔离本地页面完成 1366、1920、2560、3840、390、320 六种逻辑宽度及键盘、回收、失败写入、跨标签场景。受测页面无横向溢出，搜索文字至少 12 px；窄屏控件至少 44 px，桌面保留可见物品区域与主操作。[最终搜索报告](evidence/round15/search-final/report.json)

名称按字面包含匹配全背包，再结合槽位、品质、排序及分页。输入只更新草稿，不立即重绘或过滤；Enter 提交后焦点回到原生输入框。排序和普通导航保留草稿与已提交查询；清除名称保留品质筛选，空结果提供清除全部入口。搜索、筛选与导航不写玩法状态；真实锁定只提交一次，刷新恢复精确状态。源码复审另核对了 HTML 转义与字面查询。[独立复审](evidence/round15/gameplay/independent-search-review.md)

万件构造背包实测找到末尾物品，无须翻遍 167 页。回收入口明确标注「全背包检查（不受搜索与筛选影响）」；只匹配一件时，确认仍展示全背包安全批次。取消保留主/镜像原串；确认后的完整状态与引擎一致，锁定装备保留，两份持久化副本一致，真实刷新仍正确。[搜索及回收原件](evidence/round15/search-final/report.json)

主档写入失败时，物品、金币及初始完整状态不变，批次仍可复核。同一 run 跨标签同步保留未提交草稿和已提交搜索；较新的存档使旧回收确认失效，未执行陈旧批次。保存恢复锁、重入和批次重新校验另有独立源码复核；不能把这些受测路径扩大为所有并发时序均已覆盖。

## 死亡备战入口与原生操作

本轮使用真实留存的 seed 23757 死亡档，先经原生输入与 Enter 建立已提交查询、另一份未提交草稿及武器/品质筛选，再往返死亡页。普通导航保留它们；「调整防具」清除旧查询、草稿、品质，选择防具并重置页码；「打开背包」同时清空槽位。焦点落到可见筛选控件，纯导航前后主/镜像原串和完整状态不变。[本轮报告](evidence/round15/browser-regression/defeat-preparation/report.json)

报告覆盖六种视口、正式字号上限 1.1、比较条件与 Escape、死亡态换装、刷新、重燃、29 次真实战斗按钮点击及开箱到 loot；完整状态逐步与合法引擎动作比较。另两组明确构造天赋点及无候选/无 lastRoll 边界，不算自然旅程。死亡页面仍显示既有伤害/反击摘要；本轮恢复触发文字修正没有为它新增完整日志面板。[玩法口径](GAMEPLAY_REVIEW.md)

## 原失败、脚本假设与配置修正

| 观察 | 保留与最终证据 |
|---|---|
| 搜索初次 1366 宽字体不足 12 px；跨标签等待超时 | [原报告](evidence/round15/search-rendered/report.json) 保留；最终 10/171 单独计数，不覆盖初次失败。 |
| core 脚本固定滚动 300 px 后找完整可见锁按钮 | 实测视区高 287.58 px、该偏移完整可见锁按钮为 0。衍生脚本先保留原探针，再将实际目标滚入视区；锁定、滚动保留、设置及刷新原断言 **12/12** 通过，没有改运行源码。[推导记录](evidence/round15/core-layout-current.derivation.json) · [结果](evidence/round15/core-layout-final/report.json) |
| 生命周期首次启动失败 | PLAYWRIGHT_MODULE 指向 CommonJS 入口，动态导入未得到 chromium，启动前报错。改用对应 ESM 入口配置后，原生命周期脚本两版合计 **11/11 场景通过、0 runtime errors**。[原错误](evidence/round15/browser-regression/lifecycle.stderr) · [最终结果](evidence/round15/lifecycle-final/renderer-lifecycle-browser.json) |

生命周期覆盖正常帧、晚首帧、无 RAF 截止、首帧前跳过、模拟隐藏、低特效及减少动态。注入的帧延迟与 visibilitychange 只验证生命周期，不是普通 FPS、真实系统后台或性能提升证据。

## 验收限制

本轮使用任务授权的本地 Playwright 后备通道，Linux/Chromium 与软件渲染、隔离存档及逻辑视口；未使用私人浏览器资料。搜索组全部为构造样本；死亡组主样本虽来自自然存档，界面回放仍不等于另一条自然旅程。

已测试原生输入与键盘提交，**未操作 Windows、Android 等系统 IME**，不能声称完成候选词确认的全平台验收。实体手机、物理 4K/GPU、触笔、外部读屏、音效听测、系统挂起及真人长期体验均未验证。低特效或减少动态的功能结果不代表完整特效性能。
