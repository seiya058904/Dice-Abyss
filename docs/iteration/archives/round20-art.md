# 视觉与素材验收 · Round20 / v5.20.0

本轮把付费事件的规则转为可读的概率与预算表，沿用输入的黑底、像素边框、品质文字和数字字体。新增 4,189 字节 `src/event-risk.css`，没有新增运行时位图、字体、音频、外部字体请求或资源许可证。

## 探索与实现决定

认真比较过插画式愿骰场景、概率轮盘、密集常驻明细及原生表格。原创位图能增加气氛，但无法准确表达随幸运、价格、余额、楼层变化的概率与账目；轮盘容易让人把概率当成下一次点数预告。最终选择原生 HTML/CSS 作为本轮原创视觉方案，未调用生图生成草案，也未把未采用图像装入 ZIP。[方案比较及官方设计资料](RESEARCH.md)

主表固定点数、概率、结果三种角色，先展示当前金币、先付金额和支付后余额。品质同时用名称和颜色；退款结果列出整数退款及净支出。八品质条件表通过原生 details 展开，避免主视图常驻过多数字。确认框复用同种账目语言，但明确它针对当前所选动作。

原 8 字体/许可证文件逐字保持。本轮源文本范围的 1,057 汉字、21 CJK 标点在两字体 cmap 中均存在；197 条字体栈声明无活跃格式问题。任意导入姓名、真实 OS 输入法和外部读屏不属于此检查。[字体报告](evidence/round20/font-release.json)
