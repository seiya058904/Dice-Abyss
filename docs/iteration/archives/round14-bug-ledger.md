原 63 个测试模块、2 个原夹具、8 个字体／许可文件全部逐字保留。storage、engine、装备、内容／掉率、RNG 路线、金币、经验、比较计算、骰体 renderer、motion 和共享 timeline 的 16 个受保护核心文件与输入相同。保留 V1—V4 迁移、schema5、原键／ID、完整 expected 与 unknown 字段、Web Locks、先验证后归档、先保存后演出、当前 loot 所有权及重复动作拒绝。dawnCrit 的 nextLuck 仍由下一次实际战斗掷骰使用，离层与失败重试清除。

本轮没有确认的新增 P0/P1 阻断。故障修复、浏览器失败、严格像素差异和原自然失败均在本轮证据中保留；未测项没有被计入 PASS。
