## 完整性与运行

FILE_MANIFEST按相对路径排序，逐项真实字节数与SHA-256，唯一排除自身。每个ZIP条目在单一Dice-Abyss/目录；不含依赖、缓存、生成草案或旧ZIP。`package.json`、HTML release、`src/release.js`统一5.20.0，存档schema仍5。原Windows启动器只是现有入口文件，未在Windows实际执行。

首个实体验包实际因清单排序失败而被拒绝：Python Path默认按目录组件排序，原验证器要求完整相对路径字符串排序。生成器现显式按相对路径字符串排序，原验证器不变；首次ZIP身份、原错误、回执与修正生成器见 [packaging-first](evidence/round20/packaging-first/failure-and-correction.json)。失败发生在解压前，不存在把该次失败新目录测试改称通过的情况。最终包重新生成，后续所有门禁重新执行。

游戏无需依赖安装或线上账号。Node20+在项目根执行 `npm start`，按终端地址打开；正式运行资源本地提供。QA中可选Playwright/Python仅供验收，不是游戏运行依赖。全部源码、测试、资源、许可证和交接资料均在当前完整ZIP，下一轮不需要外部补文件才能启动。
