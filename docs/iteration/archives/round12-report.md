## 2. 选择改进的证据

先实际运行输入，再复现玩家路径。输入的“开箱→锁定→刷新→解锁”会出现背包已解锁、奖励中心与右栏仍显示解锁按钮；购买和领取也存在历史记录与背包的对象别名，导致连续运行与JSON回读的旁观记录不同。原基础装备估值没有覆盖所有条件词条；一个既有永恒目录武器的基础估值+9%，在256对相同骰与RNG的首掷中实际平均伤害却下降12.289%。满背包的行商只显示禁用购买，却没有说明限制。临近5MB的合法存档下一笔增长也会安全拒绝，玩家无法主动检查余量。

这些都有可复现的玩家后果，因此本轮优先修复与解释。没有为了制造进展修改伤害、经济、掉率、品质门槛、装备ID或存档格式。研究引用、覆盖领域与取舍见 [RESEARCH](RESEARCH.md)；视觉决定见 [ART](ART.md)。
