# 视觉与素材复核 · Round19 / v5.19.0

## 实际方案与取舍

沿用已有暗色金属框、像素标题、金色品质、青色主动作和离线中文字库。主整合者先查看输入历史搜索页与本轮真实浏览器画面，考虑独立词条插画、醒目的三张策略卡和内联控件三种方向，实际在现有页面实现并查看了内联原生选择器及两种响应式布局。

独立插画会占据背包列表空间，并可能把不同触发条件误读成自动推荐；本轮选用可复用的 HTML/CSS，未生成或引入运行位图、字体、音效或第三方资源。界面仍由玩家主动决定筛选、比较、装备与重燃。

桌面将“品质 / 生存词条 / 排序”并列；较窄窗口分三列，390/320宽将生存词条独占一行。新标签、选项及帮助实测不小于12 CSS px，窄窗输入目标至少44px。解释直接区分存活恢复、开战盾和基础减伤，不占用新的弹窗。

## 真正由看图发现的修正

首次新功能测试只检查控件和比较框，755项通过后，主整合者看图发现右侧当前防具的64字长名称把效果与来源挤进下一张遗物。输入版另用原生浏览器复现：效果行越出卡片33.171875px，来源行越出50.640625px。该构造只修改合法装备名，完整主/镜像不变。

原因是桌面五个固定等高行与不可收缩的名称/效果/来源内容相冲突。修复限定在非融合桌面侧栏：每行以内容最小高度为下限，完整列表在原区域内纵向滚动，连续英文名允许断行。没有裁掉词条或限制名字字符数。

最终同一套检查保留原755项，并加入96项侧栏内容、相邻卡片、内部截断和末卡可达性检查，实跑 **4组851项**，0运行错误，源码前后不变。四桌面尺寸×中文/连续英文各64字符均通过；两窄窗仍保持原流式布局。截图是逻辑视口验证，不是实体手机或GPU证明。
