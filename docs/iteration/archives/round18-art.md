# Round 18 · 装备角色与视觉证据

进入交换、遗物交换、无声铁砧、奉献、太古织机或空衡时，玩家可直接识别本次登记装备。消费角色用既有物品图标与“选用后永久消耗”，保留角色用锻造图标与“保留并升级的武器”；文字和真实 ID、Lv/XP/+N 承担区分，颜色辅助。

新区域采用原黑金属边框、SVG和离线字体。桌面双角色并列，窄窗单列，长名称断行；房间可打开既有比较，付款确认保持消费和保留详情且不嵌套比较按钮。内容需要滚动时沿用原房间/对话框滚动，手掷入口仍在固定操作区。

确实考虑过物品插画、纹章、新背景与直接语义信息方案。最终采用能准确体现物品身份的HTML/CSS，替换这些事件原问号装饰。imagegen调用0，新运行位图/音频/字体/依赖均0；真实浏览器截图不称作生成美术。

## 已观察结果

- 同一铁砧fixture前后截图显示问号装饰变为精确材料/保留武器，信息打开前后存档完全相同。
- 比较、取消、付款和刷新由原生点击执行，六消费路径空名称保留真实ID和XP。
- 1366×768、1920×1080、2560×1440、3840×2160、390×844、320×760逻辑视口检查装备/数字边界、横向溢出、确认滚动和长文件名错误区。
- 仅测中文长名不足以覆盖ASCII。64个连续W实际复现桌面确认溢出，局部修复后六视口通过，原负例保留。
- Space、Enter、Escape、错误区焦点和Tab重试检查具体路径，未宣称全部Tab遍历或外部读屏合规。
