## 2. 本轮选择与实际修改

### 熔炼阅读与材料操作

输入版在 1440×900 原生悬停目标卡后，详情层覆盖相邻材料中心；原生点击被拦截、选择数维持 0。旧布局只避让当前卡片。本轮按整个物品池、结算区、固定栏及所有可见操作矩形寻找可读区域；空间不足时自动预览退出，由明确的“装备详情”入口提供完整阅读。桌面 1366 / 1440 / 1920 / 2560 / 3840 均实际测量矩形和原生相邻/全选点击。

完整详情可由按钮、F2 或右键菜单打开原生 dialog，支持滚轮、选择复制、可见关闭、Tab 与 Esc 焦点回返。卡片到预览的实际指针路径跨越中间卡片时保留原阅读对象。撤销期限到达这种纯 UI 更新保持阅读；真实目标或进度改变关闭过时内容。同卡关闭抑制与真正离开后再次进入有单独保护，触控模拟关闭后不被兼容鼠标事件立即重开。

**撤回初稿误判：原版 closeTooltip 已经 clearTimeout。** 新跑原生基线在 pointerover 后 7.8 ms 按 Esc（小于 160 ms 延迟），350 ms 后仍隐藏；不能声称本轮修复了原有“待显示计时器逃过 Esc”。本轮的同卡/焦点回返防护是另一条体验路径。[原始遮挡](evidence/round05/tooltip-baseline.json)、[排除误报](evidence/round05/tooltip-baseline-escape.json)、[最终详情](evidence/round05/tooltip-current.json)

## 5. 可比性能与无法推断的结论

同一 Chrome / ANGLE SwiftShader 软件后端，1920×1080、3840×2160、Boss/永恒开箱、full/low 构成 16 窗；另有七种品质双版本 14 窗，合计 30。每格每版仅一次，固定版本顺序，没有重试或删除慢窗。30 / 30 的完整保存结果精确等于一次引擎动作且主镜像一致，0 页面/控制台错误。
