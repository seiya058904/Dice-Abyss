## 3. 玩家得到的变化

进入原有**回响熔室**即可使用工作台，无新入口或存档迁移。武器／护甲1个目标槽，遗物最多3个；目标可直接点击选入、拖拽替换或从右键菜单指定。换目标只剔除冲突或失效材料，保留仍合法的选择。

同类物品池支持名称／品质／编号搜索、品质与等级范围筛选，以及新获得、强度、等级、品质、强化、获得层6种排序。翻页可直接跳页。默认最新获得优先，当前页只创建24张卡，完整词条、与已装备／目标的差值及材料经验按需出现在浮层。

“一键熔炼”只做预选：默认排除目标、已装备、本次战利品和锁定件，明确报告排除数。传说及以上默认包含；锁定、传说及以上、或高于目标品质依旧需要原规则的保护确认。另有本页全选、当前筛选全部、取消范围与5秒撤销。

金币不足时按经验收益优先留下可支付组合，显示放入数／候选数和预算原因；可以“仍要全部放入”查看完整报价，主按钮会提供“按预算调整材料”。零预算也保持恢复入口，预选不会消耗装备、金币或随机数。单件费用有两次取整，预选使用同一报价函数，未用“单件价乘件数”近似。

六面预览、等级区间、材料数、经验、花费、余额与保护警告随结算保持可达。1440×900为6列、24张完整卡，无横向滚动。小于1050px使用固定底部结算，六面与基础经验同条显示；窄屏物品池正常纵向滚动。390px三遗物首屏没有完整无遮挡卡，滚动后可操作，不能把DOM中的24张卡称为24张同时可见。

普通材料直接投骰提交；受保护材料只弹清单与费用。完整演出有材料汇聚、目标槽与等级反馈，可以跳过；跳过仅展示已经保存的同一结果。完成结果明确显示例如**Lv.12→16、攻击62→82（+20）**，刷新后仍能读取历史结果。
