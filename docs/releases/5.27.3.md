# V5.27.3 — Inspect talents, review replacements and resume browsing

Local acceptance date: 2026-11-11. Baseline: `3060078` (V5.27.2).

## Behavior

- Selecting or focusing a talent node only inspects it. The detail panel's investment button names the actual point cost and performs the existing transaction. Nodes remain readable when points are exhausted, ranks are complete or deeper floors are locked. Pointer movement does not change the selected purchase. Keyboard focus returns to the readable node when spending becomes unavailable.
- Import review compares the current and incoming floor, level, gold and equipment count, shows the escaped filename and warns about an older revision of the same journey. Import and restart dialogs offer current-progress export without closing the pending decision. Players must confirm that the download finished before replacing progress. Primary and mirror saves remain synchronized copies, not replacement history.
- Ordinary navigation back to Inventory restores the visible page and browsing position while rebuilding results and comparisons from the latest state. Removed items/pages use current surviving results. Explicit slot shortcuts, preparation entries, changed filters and replacement journeys retain their reset rules. The remembered page follows the last visible, clamped page even if items later return.

No engine, balance, RNG, save schema/key, dependency or persistence changes are introduced. Save schema remains 5. Exports preserve supported extra fields; imports and purchases retain the complete-snapshot checks, Web Locks serialization and primary/mirror failure contracts.

Deployment additionally requires successful syntax/unit, 1,000-seed simulation and all four browser shards for the publishing commit. Local checks alone do not establish a successful deployment.
